# Windhawk Mods

This Markdown file provides Mods IDs from [Windhawk](https://windhawk.net/) that enhance the Windows Experience ever so slightly with Quality of Life Code Snippets.

- Warning: I have had some bad experiences with some WindHawk mods, especially the "Windows 11 ... Styler"s that customize certain Windows Functions such as Notification Center, File Explorer and more. They dont break the System, but some Themes don't get applied properly, and sometimes a total PC Restart is needed to get rid of the Theme. Download at your own Caution.
